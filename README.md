# 地图题口袋卡

雅思听力地图题复习网页，包含 132 条表达、翻卡背诵、句子自测、速览词表与考前避坑。

访问地址：https://flyyuan1.github.io/ielts-map-pocket/

页面与字体均内嵌，不依赖外部脚本或字体服务。支持邮箱登录后跨设备同步熟悉度与背诵位置：未登录时进度保存在当前浏览器；登录同一账号后手机与电脑共享进度，断网时继续保存、联网后自动补同步。

账号进度存储在 Supabase（`ielts-practice` 项目），每个账号只能读写自己的记录。认证配置与数据库迁移托管在服务端，本仓库不保存任何服务端密钥或用户密码。

- `index.html`：在线页面（含登录与同步）
- `offline.html`：可下载到本地使用的离线页面，不包含账号信息
- `account/`：同步逻辑、认证封装与账号界面源码
- `supabase/migrations/`：私有进度表、行级权限与事务合并函数
- `地图题背诵卡.tsv`：卡片导出文件
- `Inter-LICENSE.txt`：内嵌字体的许可证

本地开发：

```bash
npm install --ignore-scripts
npm test
npm run build
```

朗读由设备的浏览器语音功能提供，可用性和声音取决于设备。
